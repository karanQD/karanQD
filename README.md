## `engineering_philosophy`

> **Correct before clever.** A system that works predictably is worth more than one that works brilliantly on average.

> **Measure before optimizing.** Profilers, not intuition. The bottleneck is almost never where you think it is.

> **Understand your hardware.** Cache lines, branch predictors, memory bandwidth — ignoring them is ignoring half the problem.

> **Complexity is a liability.** Every abstraction has a cost. Earn it.

> **Build systems that fail loudly.** Silent errors are the most expensive kind.

> **The interface is the design.** If the API is hard to use correctly, the implementation doesn't matter.
